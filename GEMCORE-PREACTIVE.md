# GemCore Pre-Active Build

GemCore is wired into the GOAT runtime on this branch.

## Run locally

npm install
npm run dev:web

Open `/gemcore` for the grading lab, `/app/gemcore-evidence-passport.html` for the Evidence Passport, and `/api/gemcore/health` for API health.

Included: touch/spatial grading UI, microscope/telescope controls, VisionCore prototype scan, Evidence Passport, evidence schema, prototype API, human-QC gate, and Hostinger preflight.

The current score animation is demonstrative. Real certification requires calibrated capture, implemented measurement/vision models, authenticated persistent storage, verified rubric logic, and human QC.
