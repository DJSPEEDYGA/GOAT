# GemCore Grading — Standalone Pre-Active Build

This directory is the standalone GemCore application source. It does not depend on the GOAT Royalty UI/runtime.

## Run
```bash
cd gemcore
npm install
npm test
npm start
```
Open http://localhost:4300

## Docker
```bash
docker compose up --build
```

## Current implementation
Responsive cinematic dashboard shell; Command Center; Quantum Inspection; intake; submissions/Evidence Passport; Vault; Market; Live; Population; Settings/Calibration; Human QC; standalone Express API; persistent JSON pre-active store; Docker; smoke test.

## Integrity
The 9.8* scan is explicitly demo-only. Production certification requires calibrated capture, real VisionCore adapters/models, versioned scoring logic, authenticated database storage, and human QC.
